# Lab-Material

Hier entstehen Szenarien, Ablaufpläne und Prompt-Vorlagen für die Teams. Das Lab-Material ist auf
Deutsch; Beispielprompts gibt es auf Deutsch und Englisch.

Geplante Inhalte:

- `szenarien/`: je Szenario Ziel, Welt, Profil (`einzel`, `duo`, `koordinator`), Endbedingung.
- `ablauf.md`: Zeitplan eines Lab-Tages.
- `prompts/de/`, `prompts/en/`: Startprompts für Teams, bewusst unvollständig, in beiden Sprachen
  mit gleichem Dateinamen.
- Übungen zu Prompt-Injection, Lügendetektor (Bericht gegen Protokoll) und Token-Kosten.
